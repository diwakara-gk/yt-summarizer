🔑 Manage your Gemini API key

Saved once, used automatically every time you summarize.

Your key is stored in an HttpOnly, Secure cookie for 16 hours. It's sent straight to this app's server over HTTPS and nowhere else. Page JavaScript can't read it, localStorage never sees it, and because browser extensions can only access cookies through document.cookie (which HttpOnly blocks), they can't read it either. After 16 hours, or if you hit "Clear key," it's gone and you'll need to save it again.

Keys never leave this server — not even to page JavaScript.
